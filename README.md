# SafeSpace Storyboard

Хронологическая карта сюжетных и личных эпизодов [SafeSpace](https://safespace.rusff.me), включая текущие и архивные темы. Альтернативные эпизоды не входят в набор данных.

Проект публикуется через GitHub Pages из папки `/docs`. Исходный снимок форума хранится в `src/episode-source.json`, а воспроизводимая сборка использует только встроенные модули Node.js 22+.

## Разработка

```sh
npm test
npm run build
```

Устанавливать зависимости не требуется.

## GitHub Pages

В настройках репозитория выберите `Settings → Pages → Deploy from a branch → main → /docs`.

В форумное сообщение вставляется содержимое `forum-embed.txt`. Оно загружает полное приложение через `iframe` и остаётся значительно короче ограничения форума в 65 000 символов. После значимого обновления увеличьте значение `?v=` в адресе, чтобы сбросить кэш iframe.

Аватары обновляются отдельно командой `node scripts/cache-avatars.cjs`; скрипт сохраняет только PNG, JPEG, GIF и WebP с проверенной сигнатурой. Форумные логин и пароль в репозитории не хранятся.
